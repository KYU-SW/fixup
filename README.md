# Gluvi

**ECG 신호 기반 1형 당뇨 저혈당 조기 탐지 시스템**

CGM과 채혈 없이, 흉부 ECG만으로 저혈당을 조기에 탐지해 알려주는 웹 시스템입니다.

## 왜 만드나요?

1형 당뇨 환자는 저혈당을 일상적으로 겪지만, 손끝 채혈은 아프고 번거롭고, 연속혈당측정기(CGM)는 비용과 절차 부담으로 국내 환자의 약 89%가 지속적으로 쓰지 못하고 있습니다. Gluvi는 이 공백을 메우는 **보조 경보**를 목표로 합니다.

## 어떻게 동작하나요?

```
흉부 ECG → 신호 품질 확인 → 특징 추출(심박수, HRV, QT·T파) → 개인 평소 대비 변화 → 저혈당 조기 탐지 → 경보
```

- 저혈당이 오면 심장이 반응해 심박수와 심전도 파형이 달라지는 점을 이용합니다.
- 혈당 수치를 재는 것이 아니라, 저혈당 **발생**을 탐지합니다.
- 공개 데이터셋 D1NAMO와 PhysioCGM으로 처음 보는 환자에게도 통하는지 검증합니다.
