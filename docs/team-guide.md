# Gluvi 팀 가이드

> 처음 합류한 팀원이 "우리가 뭘 왜 하는지"를 이해하고, 발표 질문에 대비할 수 있도록 정리한 설명용 문서입니다.
> 공식 내용은 [project-plan.md](project-plan.md)가 기준입니다. 두 문서가 다르면 계획서를 따릅니다.

## 1. 배경 지식

### 1형 당뇨와 저혈당
- 1형 당뇨 환자는 몸에서 인슐린이 거의 나오지 않아서 인슐린을 직접 주사합니다.
- 인슐린이 많거나, 밥을 적게 먹거나, 운동을 많이 하면 혈당이 너무 떨어지는 **저혈당**이 생깁니다.
- 저혈당은 어지럼증, 의식 저하, 심하면 사망까지 이어질 수 있는 **급성 위험**입니다.
- 저혈당이 와도 본인이 알아차리지 못하고 지나가는 경우가 많아서, **외부에서 알려주는 수단**이 필요합니다.

### CGM (연속혈당측정기)
- 피부에 센서를 꽂아 5분마다 혈당을 자동으로 재는 기기입니다.
- 저혈당 관리에 가장 좋은 도구지만, **비용 부담, 번거로운 환급 절차, 센서 착용 불편** 때문에 국내 1형 당뇨 환자의 약 89%가 지속적으로 쓰지 않습니다.

### 저혈당이 오면 심전도가 왜 변하나?
- 혈당이 떨어지면 뇌가 이를 감지하고, 몸이 비상 상황으로 인식해서 아드레날린을 분비합니다.
- 인슐린과 아드레날린이 혈중 칼륨을 세포 안으로 밀어 넣어 칼륨도 떨어집니다.
- 그 결과 심장 박동과 전기 신호 모양이 변합니다. 즉 ECG 변화는 **저혈당이 먼저 오고 심장이 반응한 결과**입니다.

| 변화 | 쉽게 말하면 |
|---|---|
| 심박수(HR) 증가 | 심장이 빨리 뜀 |
| 심박변이도(HRV) 변화 | 박동 간격의 자연스러운 흔들림이 달라짐 (특히 LF 성분 감소) |
| QT 간격 연장 | 심장이 한 번 뛰고 회복하는 시간이 길어짐 |
| T파 평탄화 | 심전도 파형 중 회복 구간의 봉우리가 낮아짐 |

### "알려진 것"과 "우리가 확인할 것"

| 구분 | 내용 |
|---|---|
| 알려진 것 | 저혈당 **중**에는 위와 같은 ECG 변화가 나타난다 (저혈당을 못 느끼는 환자 포함) |
| 일부 근거 있음 | 소아 야간 데이터에서 저혈당 **70분 전부터** HRV 변화 보고 (학회 초록) |
| 우리가 확인할 것 | 성인 **낮** 데이터에서도 저혈당 **직전**에 변화가 시작되는가 |

## 2. 왜 이렇게 정했나

### 왜 혈당 수치가 아니라 저혈당 "이벤트"인가?
- 비침습적으로 혈당 **수치**를 재려는 시도는 수십 년간 많았지만 대부분 실용화에 실패했습니다.
- ECG가 혈당 수치를 연속적으로 반영한다는 근거는 약합니다.
- 반면 저혈당은 교감신경 반응이라는 생리적 근거가 있어서, 이벤트 탐지가 현실적입니다.

### 왜 "예측"이 아니라 "조기 탐지"인가?
- 확실한 근거는 "저혈당 **중**에 ECG가 변한다"입니다. "30분 **전**에 변한다"는 아직 가설입니다.
- 저혈당은 본인이 모르고 지나가는 경우가 많아서, **시작 직후에만 잡아도** 의미가 있습니다.
- 정답 구간을 "시작 30분 전 ~ 시작 후 15분"으로 잡아서, 직전 변화가 있으면 사전 탐지로, 없으면 시작 직후 탐지로 과제가 성립합니다.

### 왜 ECG만 쓰나? (교수님 피드백 반영)
- 식사·인슐린 기록은 정확도가 낮고(영양사 추정치, 자가 기록) 빠진 기록이 많아, 작은 데이터에서 역효과를 낼 수 있습니다.
- 인슐린 투여 시각처럼 저혈당과 강하게 엮인 변수가 들어가면, 모델이 ECG 대신 그걸로 맞춰서 "ECG가 저혈당을 잡는다"를 증명할 수 없습니다.
- 추가 데이터셋(PhysioCGM)에는 이 기록이 없어서, ECG 단독이어야 두 데이터셋을 합칠 수 있습니다.
- 환자가 아무것도 입력하지 않아도 되는 시스템이 됩니다.
- 가속도계는 같은 가슴 기기가 자동으로 재는 값이라, **모델 입력이 아니라 신호 품질 판정용**으로만 씁니다. 운동으로 오른 심박수를 저혈당으로 착각하지 않게 해줍니다.

### 왜 데이터셋을 두 개 쓰나? (교수님 피드백 반영)
- D1NAMO만으로는 환자 9명, 낮 4일 분량이라 저혈당 사례가 부족할 수 있습니다.
- ECG 원신호 + CGM + 1형 당뇨를 갖춘 공개 데이터는 D1NAMO와 PhysioCGM 두 개뿐이고, 둘 다 같은 가슴 기기로 측정해서 같은 코드로 처리할 수 있습니다.
- 합치는 효과 자체를 실험(학습 3종 × 테스트 2종)으로 검증하고, 합치면 안 되는 기준도 미리 정해두었습니다.

### 왜 LOSO(한 명씩 빼고 테스트)인가?
- 환자 데이터를 섞어서 나누면, 모델이 같은 사람의 비슷한 시간대 데이터를 보고 맞추기 때문에 성능이 크게 부풀려집니다.
- 실제로 쓰일 상황은 "처음 보는 환자"이므로, 한 명씩 빼고 테스트해야 정직한 성능이 나옵니다.

## 3. 자주 나올 질문 (발표 대비)

**Q. CGM이 있으면 그걸 쓰면 되지 않나요?**
A. 맞습니다. CGM이 있으면 CGM이 가장 정확합니다. 저희는 CGM을 대체하려는 게 아니라, **국내 1형 당뇨 환자 대부분이 CGM 없이 생활하는 공백**을 메우려는 것입니다. 그래서 비교 기준도 CGM이 아니라 CGM이 없을 때 쓸 수 있는 **심박수 기반 웨어러블 수준(E1)**입니다.

**Q. 그러면 처음 주제와 다른 것 아닌가요?**
A. 처음부터 주제는 "CGM 없이 저혈당을 잡아내는 것"이었고, 계획서 과제 개요에 그렇게 정의돼 있습니다. 비용·불편으로 착용을 중단한 환자, 센서 교체·부착 초기, 센서 탈락·통신 끊김 같은 경우가 대상입니다.

**Q. ECG로 혈당을 측정하는 건가요?**
A. 아닙니다. 혈당 **수치**가 아니라 저혈당 **발생**을 탐지합니다.

**Q. 경보가 울리면 결국 채혈해야 하지 않나요?**
A. 맞습니다. 저혈당 처치 전 확인은 안전상 필요해서 경보 시 혈당측정기 확인을 안내합니다. 대신 평소에는 채혈 없이 감시하므로, 언제 재야 할지 모른 채 반복하던 채혈을 **경보 시 확인**으로 줄입니다.

**Q. 왜 식사나 인슐린 기록은 안 쓰나요?**
A. 2장 "왜 ECG만 쓰나?" 참고.

**Q. 예측이 아니라 탐지면 이미 늦은 것 아닌가요?**
A. 저혈당은 본인이 알아차리지 못하고 지나가는 경우가 많아서, 시작 직후에라도 알려주면 심해지기 전에 대처할 수 있습니다. 정답 구간에 시작 30분 전까지 포함해서 사전 탐지도 함께 평가합니다.

**Q. 저혈당 전에도 ECG가 정말 변하나요?**
A. 소아 야간 데이터에서 70분 전부터 HRV가 변했다는 예비 보고가 있지만, 성인 낮 데이터에서는 확인이 필요합니다. 그래서 1층 통계 분석으로 먼저 확인합니다.

**Q. 두 데이터셋을 합쳐도 되나요?**
A. ECG 기기와 측정 환경이 같아 합칠 근거가 있고, 합치는 효과 자체를 실험으로 검증합니다. 합치면 안 되는 기준도 미리 정해두었습니다.

**Q. 기존 ECG 저혈당 연구와 뭐가 다른가요?**
A. ECG 기반 연구는 건강인 대상이거나, 같은 사람의 데이터를 나눠 학습·테스트했습니다. 저희는 1형 당뇨 환자를 **처음 보는 환자(LOSO)**로 검증하고, **두 공개 데이터셋을 서로 외부 검증**에 씁니다.

**Q. 스위스 Bern 연구(Lehmann 2023)와는 뭐가 다른가요?**
A. Bern 연구는 손목 기기 2개(심박·HRV·피부전도)로 처음 보는 사람에게서 저혈당을 **검출**했습니다(22명, AUROC 0.76). 저희는 ① 흉부 단일 ECG로 **QT·T파 같은 파형 정보**까지 쓰고, ② **조기 탐지**를 목표로 하며, ③ **공개 데이터 2개로 교차 검증**합니다. 실험 B의 E1·E2(손목 기기와 비슷한 수준)와 E3·E4(파형 추가) 비교가 "ECG 파형이 손목 기기 이상의 정보를 주는가"를 확인하는 실험입니다.

**Q. 19명으로 AI가 되나요?**
A. 사람 수는 적지만 기록 시간이 수백 시간이라 분석할 구간은 꽤 됩니다. 데이터가 적어도 잘 되는 특징 기반 모델을 메인으로 쓰고, LOSO로 과대평가를 막습니다. 주장 수준도 **가능성 확인(feasibility)**으로 한정합니다.

**Q. 의료기기인가요?**
A. 아닙니다. 진단이 아닌 보조 경보로 범위를 한정한 연구 수준 시스템입니다. 실제 서비스로 간다면 저혈당 경보가 의료 목적이라 의료기기 소프트웨어(SaMD) 검토가 필요합니다.

**Q. 하드웨어를 만드나요?**
A. 아닙니다. ECG 신호를 받아 탐지하는 소프트웨어를 만들고, 공개 데이터셋 신호를 재생해서 검증합니다.

**Q. 스마트워치에도 쓸 수 있나요?**
A. 스마트워치 ECG는 손가락을 대고 30초 재는 **수동 측정**이라 연속 감시가 안 됩니다. ECG 파형까지 쓰는 모델(E3, E4)은 **흉부 스트랩이나 패치형** 연속 ECG 기기가 대상입니다. 스마트워치가 연속으로 재는 심박수는 E1 수준 정보에 해당합니다.

## 4. 용어 정리

| 용어 | 뜻 |
|---|---|
| ECG | 심전도. 심장의 전기 신호 |
| 단일 리드 | 전극 2개로 측정한 1채널 심전도 |
| PPG | 광학 센서로 혈류를 재는 방식. 스마트워치 심박수 측정에 사용 |
| CGM | 연속혈당측정기 |
| 블라인드 CGM | 환자가 측정값을 실시간으로 볼 수 없는 방식 |
| HR / HRV | 심박수 / 심박변이도 |
| QTc | 심박수로 보정한 QT 간격 |
| 대표 박동 | 5분 동안의 박동을 평균 낸 하나의 박동 모양 |
| HRC | Zephyr 기기가 기록하는 심박 신뢰도 |
| bSQI | 두 R피크 검출기 결과의 일치도로 보는 신호 품질 지표 |
| 저혈당 무자각 | 반복된 저혈당 등으로 경고 반응이 약해져 저혈당을 잘 못 느끼는 상태 |
| 압박 아티팩트 | 자는 동안 CGM 부위가 눌려 실제보다 낮게 찍히는 현상 |
| 조기 탐지 구간 | 정답으로 인정하는 구간. 저혈당 시작 30분 전 ~ 시작 후 15분 |
| 탐지 시점 | 경보가 저혈당 시작 기준 몇 분에 울렸는지 (음수 = 시작 전) |
| LOSO | 한 명씩 빼고 테스트하는 평가 방식 |
| 외부 검증 | 학습에 쓰지 않은 다른 데이터셋으로 테스트 |
| AUPRC | 드문 사건을 얼마나 잘 찾는지 보는 지표 |
| SaMD | 의료기기 소프트웨어 |
| mmol/L | 혈당 단위 (3.9 mmol/L ≈ 70 mg/dL) |
